# مُخطّطي (Mukhattati) 🕌📅💰

**مُخطّطي** هو تطبيق ويب تقدمي (PWA) عربي باللهجة المصرية، مبني بالكامل بـ Vanilla HTML + CSS + ES Modules من غير أي فريمورك أو خطوة Build.

## أهم المميزات
- **اليوم وقوس الشمس:** هيرو تفاعلي بيمثّل حركة الشمس بين الصلوات الخمس مع خلفية سماء القاهرة (الفجر، النهار، الغروب، الليل) وعدّ تنازلي للصلاة الجاية.
- **إضافة سريعة ذكية (`parseQuick`):** اكتب جملة عادية زي «مذاكرة الساعة 11:50» أو «اجتماع بكرة 5 مساءً» أو «مشوار السبت 7 م» والتطبيق يستخرج العنوان والتاريخ والوقت تلقائياً.
- **مواقيت الصلاة والأذان وحوار «والله صليت»:** حساب دقيق بالطريقة المصرية والمذهب الشافعي لمدن مصر أو بموقعك الجغرافي، مع حوار إجباري عند الأذان.
- **حاسبة الميزانية والصرف اليومي:** احسب المسموح تصرفه يومياً بعد خصم المواصلات والالتزامات الشهرية والادخار الاختياري.
- **لوحتي وتقرير آخر اليوم:** ملخص يومي تلقائي لنسبة الإنجاز وحالة الصلوات الخمس مع رسم بياني لأيام الأسبوع، وإمكانية إرساله على الإيميل.
- **وضع محلي أو سحابي:** يشتغل فوراً على جهازك من غير حساب، أو بمزامنة سحابية عبر Supabase + Google.

## التشغيل المحلي
بما أن المتصفحات تمنع تحميل ES Modules مباشرة من `file://`، شغّل سيرفر محلي بسيط من داخل الفولدر:

```bash
python3 -m http.server 8123
# أو باستخدام Node:
npx serve -l 8123
```
ثم افتح المتصفح على الرابط: `http://localhost:8123`

## تشغيل الاختبارات
```bash
node scripts/check-shared.mjs
node tests/unit.mjs
node tests/e2e.js
```

لخطوات النشر على Vercel وربط Supabase وGoogle OAuth وإيميل التقرير، راجع ملف **[SETUP.md](./SETUP.md)**.
